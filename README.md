Programa em linguagem Python que visa fazer uma pesquisa de opinião sobre o atendimento de um serviço prestado, no qual são coletados os dados e oferecido escolhas, no final é feito a contagem total de votos para cada opição, originalmente para 50 entrevistas, porém 10 para teste.
